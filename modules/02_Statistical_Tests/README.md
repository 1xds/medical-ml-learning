# Module 02: 统计检验

## Statistical Tests

> 阶段 1: 基础入门

---

## 为什么医学数据需要这个？

医学研究广泛使用统计检验来验证组间差异。选错检验方法或忽略多重比较校正，是医学论文被拒的常见原因。

---

## 学习目标

- [ ] 理解假设检验的基本逻辑（H0/H1、p值、显著性水平）
- [ ] 掌握 t 检验、Mann-Whitney U 检验的使用场景
- [ ] 掌握卡方检验用于分类变量关联分析
- [ ] 理解多重比较问题与 Bonferroni 校正
