# Module 07: 防数据泄漏

## Data Leakage Prevention

> 阶段 3: 建模评估

---

## 为什么医学数据需要这个？

医学AI论文中数据泄漏是最常见的致命错误之一。一旦泄漏，模型性能虚高，临床部署后会造成严重后果。

---

## 学习目标

- [ ] 理解数据泄漏的定义与危害
- [ ] 掌握训练/测试集划分的正确顺序
- [ ] 理解预处理泄漏（先标准化后划分的错误）
- [ ] 学会使用 Pipeline 防止泄漏
- [ ] 理解时间序列数据中特有的泄漏模式
