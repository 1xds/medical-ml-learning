# Module 14: SHAP 依赖图

## SHAP Dependence Analysis

> 阶段 4: 可解释性与因果

---

## 为什么医学数据需要这个？

医学变量与结局常呈非线性关系（如血压与心血管风险呈J型）。SHAP依赖图能直观展示这种非线性。
