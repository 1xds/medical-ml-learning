# Module 03: 数据预处理

## Data Preprocessing

> 阶段 2: 特征工程

---

## 为什么医学数据需要这个？

医学数据混合了连续变量（年龄、BMI）、分类变量（性别、分期）和缺失值，预处理质量直接决定模型上限。

---

## 学习目标

- [ ] 掌握缺失值处理的多种策略（删除/填充/插补）
- [ ] 理解标准化 vs 归一化的区别与选择
- [ ] 掌握分类变量编码（One-Hot / Label / Target Encoding）
- [ ] 学会使用 Pipeline 构建可复用的预处理流程
- [ ] 理解预处理顺序对数据泄漏的影响
