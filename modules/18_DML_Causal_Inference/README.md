# Module 18: 双重机器学习因果推断

## Double Machine Learning (DML)

> 阶段 4: 可解释性与因果

---

## 为什么医学数据需要这个？

医学研究关心治疗是否有效（因果），而非治疗与结局是否相关。DML能在观察性数据中估计因果效应。
