## 笔记规则

- 每篇笔记对应一个**知识点**，不是日记
- 写自己的理解，不抄教程
- 包含：核心概念 → 代码要点 → 踩坑记录 → 可复用片段
- 学完一个知识点就整理一篇，不赶频率
