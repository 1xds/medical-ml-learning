一、发散（Brainstorm）  目标：帮助规划实验方案、提供可选思路
提示词
我正在完成一个医学机器学习实验。
实验内容：基于乳腺超声BUSI数据集，利用病灶 ROI 提取影像组学特征，实现良恶性分类。
数据概况：BUSI 数据集，3 个类别 — benign（437 张）、malignant（210 张）、normal（133 张），每张图都有对应的 mask（部分有多张 mask）。
基本要求包括：
- 提取一阶统计、形状、纹理等影像组学特征；
- 比较 Logistic Regression 与一种非线性模型（SVM、Random Forest 或 XGBoost）；
- 输出 Accuracy、Sensitivity、Specificity、AUC；
- 绘制 ROC 曲线、混淆矩阵和前10个关键特征重要性图；
- 对最优模型进行可解释性分析。

可以从以下角度发散：
- 数据预处理
- 特征提取
- 特征筛选
- 模型选择
- 模型评估
- 可解释性分析
- 可视化
- 实验规范
- 结果分析
- 实验报告

请站在实验设计者的角度，提出10种可以采用的实验设计思路或实现方案。

要求：
① 每个思路尽量不同；
② 至少3个属于课程要求之外的拓展方向；
③ 简要说明每种方案的优点和适用场景。

二、迭代（Refine）     目标：筛选真正适合课程实验的方案。
提示词
刚才提出了10种实验设计方案。
另外，老师给出的拓展任务包括：
- 特征筛选或降维；
- 交叉验证和超参数优化；
- SHAP 个体预测解释；
- 在外部乳腺超声数据集上验证。

请结合老师提供的拓展任务，以及课程实验的工作量，对刚才的10种方案进行重新筛选。

要求：
1. 优先保留既符合课程要求，又与老师拓展任务一致的方案；
2. 如果老师没有提到，但你认为很有价值，也可以保留，并说明原因；
3. 将最终方案分为：
   - 必须完成
   - 推荐完成
   - 有余力再做
4. 简要说明每个保留方案的理由。
最后重新整理成推荐列表。

三、收敛（Decision）     目标：选出最终实施方案。

提示词
根据上一轮筛选结果，请帮助我确定最终实验方案。
我的目标是：
- 满足课程实验的全部要求；
- 尽量覆盖老师提供的拓展任务；
- 控制整体工作量，保证能够按时完成；
- 最终形成一份完整的 Notebook 和 3～5 页实验报告。

请从以下四个维度对保留的实验方案进行评分（1～5分）：
1. 与课程要求的匹配程度；
2. 对实验结果质量的提升；
3. 对实验报告展示效果的提升；
4. 实现难度（越容易实现分数越高）。

请完成以下内容：
① 给出每个方案的评分表，并简要说明评分理由；
② 综合评分和课程实验的实际情况，确定最终采用的实验方案，并说明保留或放弃各方案的原因；
③ 给出最终实验流程，包括：
- 数据预处理；
- 影像组学特征提取；
- 特征筛选；
- 模型训练与比较；
- 模型评估；
- 可解释性分析；
- 可选拓展实验（如有）。
④ 用 Mermaid 流程图展示最终实验流程。
⑤ 用一段话总结为什么这是最适合本课程实验的方案。

四、深化（Implementation）   目标：把最终方案拆成可执行步骤。
提示词
我已经确定最终实验方案如下：
- BUSI 数据集与 ROI 掩膜；
- 提取影像组学特征（一阶统计、形状、纹理等）；
- 特征筛选；
- Logistic Regression 与 Random Forest 模型比较；
- 5 折交叉验证与 GridSearchCV 超参数优化；
- 模型评估（Accuracy、Sensitivity、Specificity、AUC、ROC、混淆矩阵）；
- SHAP 可解释性分析；
- （可选）类别不平衡处理和错误病例分析。

请将该实验进一步细化为可执行的 Notebook 实施方案。

要求：
1. 按 Notebook 的章节划分整个实验流程，并说明每一章的目标；
2. 给出每一步需要完成的主要任务和预期输出结果（如特征矩阵、模型性能指标、ROC 曲线、混淆矩阵、SHAP 图等）；
3. 对涉及机器学习流程的步骤，按照规范顺序进行设计，避免数据泄漏（如 Train/Test Split、StandardScaler、特征筛选、交叉验证等）；
4. 给出推荐的项目目录结构和 Notebook 组织方式；
5. 说明每个 Notebook 章节对应实验报告应撰写的内容；
6. 最后生成一份完整的 Mermaid 实验流程图，反映最终实现流程。
