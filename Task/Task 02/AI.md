一、发散（Brainstorm）  目标：帮助规划实验方案、提供可选思路
提示词
我正在完成一个医学机器学习实验。
实验内容：基于乳腺超声BUSI数据集，利用病灶 ROI 提取影像组学特征，实现良恶性分类。
数据概况：BUSI 数据集，3 个类别 — benign（437 张）、malignant（210 张）、normal（133 张），每张图都有对应的 mask（部分有多张 mask）。
基本要求包括：
- 提取一阶统计、形状、纹理等影像组学特征；
- 比较 Logistic Regression 与一种非线性模型（SVM、Random Forest 或 XGBoost）；
- 输出 Accuracy、Sensitivity、Specificity、AUC；
- 绘制 ROC 曲线、混淆矩阵和前10个关键特征重要性图；
- 对最优模型进行可解释性分析。

可以从以下角度发散：
- 数据预处理
- 特征提取
- 特征筛选
- 模型选择
- 模型评估
- 可解释性分析
- 可视化
- 实验规范
- 结果分析
- 实验报告

请站在实验设计者的角度，提出10种可以采用的实验设计思路或实现方案。

要求：
① 每个思路尽量不同；
② 至少3个属于课程要求之外的拓展方向；
③ 简要说明每种方案的优点和适用场景。

二、迭代（Refine）
目标：筛选真正适合课程实验的方案。

提示词
刚才提出的10个优化方案中，请结合以下实际情况重新筛选。
我的限制条件：
- 使用 BUSI 数据集；
- Python 3.12 环境；
- 不使用 PyRadiomics；
- 使用 scikit-image 自行提取影像组学特征；
- 实验时间有限；
- 最终需要提交 Notebook 和3~5页实验报告。

请去掉实现成本过高或不适合课程实验的方法。
另外增加2个更适合作为课程实验亮点的优化建议。
最后重新整理成推荐列表。

三、收敛（Decision）
目标：选出最终实施方案。

提示词
请对目前推荐的优化方案进行评分。
评分标准：
① 实现难度（越低越好）
② 对模型性能提升的帮助
③ 对实验报告质量的提升
④ 对课程评分的帮助
每项满分5分。
请汇总成评分表，并最终推荐最值得实现的3项优化，同时说明推荐理由。

最终可以写：
我最终选择：
Feature Selection（特征筛选）
Random Forest Feature Importance（特征重要性分析）
5折交叉验证

四、深化（Implementation）
目标：把最终方案拆成可执行步骤。

提示词
我最终决定在乳腺超声影像组学分类实验中增加以下三个优化：
1. 特征筛选（SelectKBest）
2. Random Forest 特征重要性分析
3. 五折交叉验证

请帮我制定详细实施计划。

要求：
按照 Notebook 编写顺序说明：
① 在哪一步加入
② 使用哪些 Python 库
③ 需要调用哪些 sklearn API
④ 每一步输出什么结果
⑤ 最终如何在实验报告中进行分析
尽量给出具体操作流程，而不是理论介绍。
